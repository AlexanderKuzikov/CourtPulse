# CourtPulse

Мониторинг доступности сайтов судов ГАС «Правосудие» (Пермский край, регион 59).

**Проблема:** при парсинге судов (sudrf.ru / msudrf.ru) сайты регулярно недоступны: WAF-баны (403/429), DNS-сбои, таймауты, кривые сертификаты. CourtPulse круглосуточно проверяет главные страницы всех 181 сайта судов региона раз в 15 минут и собирает статистику доступности.

**Что делает:**
- Проба каждого суда: DNS → TCP → TLS → HTTP GET `/` (капчи на главной нет — это честная проверка живости)
- Классификация: `OK` / `BANNED` (403/429) / `HTTP_ERR` / `DNS_FAIL` / `CONNECT_FAIL` / `TLS_FAIL` / `TIMEOUT`
- Волны проб каждые 15 мин, конкаренси 2, jitter — чтобы не словить WAF-бан самому
- Детект инцидентов: суд недоступен ≥3 проб подряд → инцидент с длительностью
- Дашборд: KPI, график доступности региона за 7 дней, таблица судов с uptime, инциденты, таймлайн каждого суда

**Стек:** Node ≥22.6 (TypeScript нативно, `--experimental-strip-types`), ноль зависимостей. UI — vanilla JS + uPlot (локальный файл).

## Команды

```bash
npm start      # мониторинг + дашборд http://127.0.0.1:8781
npm run once   # одна волна проб и выход
npm run dev    # watch-режим
```

## API

| Route | Описание |
|---|---|
| `/api/summary` | KPI региона: доступны/бан/лежат, uptime 24ч/7д |
| `/api/courts` | Список судов + последний статус + uptime 24ч |
| `/api/history?code=&days=` | Сырые пробы (фильтр по суду) |
| `/api/incidents?days=` | Инциденты |

## Данные

- `data/courts.json` — справочник судов (копия из CourtDesk, 10 287 судов РФ, фильтр по региону)
- `data/probes/YYYY-MM-DD.jsonl` — сырые пробы
- `data/state.json` — последние статусы
- `data/incidents.json` — инциденты

## Расширение

Регион меняется в `src/config.ts` (`region: '59'`). Справочник покрывает все регионы РФ — для нового региона достаточно сменить код.
